Un minuteur donne un ordre d'idée ; c'est rarement lui qui dit au cuisinier que la préparation est prête. Une crème anglaise est cuite quand elle nappe la cuillère, des jaunes blanchis quand ils retombent en ruban, un beurre quand il sent la noisette. Un <Term id="targetState" link={false} /> note ce repère visuel ou sensoriel avec `={...}` :

```gram
[Fouetter] Les @jaunes{4} avec le @sucre{80 g} jusqu'au ={ruban}.

[Cuire] Dès que le beurre est ={noisette}, retirer la #poêle du feu.

[Monter] Les blancs doivent être ={fermes} avant d'y verser le @sucre{50 g}.
```

Placez l'état attendu là où la phrase le demande — en fin, début ou milieu d'étape — sans formule imposée (« jusqu'à », « dès que », « quand », ou rien du tout). Ne placez entre les accolades que l'état lui-même, en laissant les mots de liaison dans la phrase : l'étape reste fluide tout en mettant le repère en valeur dans chaque vue.

## Comment le vérifier

Une précision entre parenthèses, collée à l'accolade fermante, indique comment contrôler que l'état est atteint — le test concret auquel se fier :

```gram
[Cuire] Sur ^{feu doux} en remuant jusqu'à ={la nappe}(un doigt passé sur le dos de la cuillère laisse une trace nette) ->&crème anglaise{}
```

L'état et sa précision sont toujours affichés, à l'écran comme sur papier, et `gram cook` les met en avant sous l'étape. Gram les conserve tels quels dans la langue de la recette, sans chercher à les interpréter.

Comme pour les ingrédients, le matériel et les températures, la parenthèse ouvrante reste collée à `}` sur la même ligne : avec un espace (`={bec d'oiseau} (environ 5 min)`), elle redevient du texte ordinaire.

## Avec une durée et une température

Une étape peut associer un état attendu à un minuteur et une température. Le minuteur donne l'estimation pour le planning ; l'état dit quand arrêter la cuisson.

```gram
[Cuire] À ^{82°C}(à cœur) pendant ~{8 min}, jusqu'à ={la nappe}.
```

:::tip[Ce qui n'a pas sa place entre les accolades]
Un état attendu décrit un état sensoriel, jamais une mesure :
- une température cible est une [température](/fr/docs/reference/syntax/temperatures/) avec sa précision (`^{63°C}(à cœur)`) ;
- une durée est un [minuteur](/fr/docs/reference/syntax/times/) (`~{5 min}`) ;
- un état attendu ne change jamais d'échelle (`={doublé de volume}` reste tel quel quel que soit le nombre de portions).
:::

## Plusieurs états dans une étape

Une étape peut contenir plusieurs états attendus. Chacun s'affiche à sa place dans le texte, et `gram cook` les regroupe pour vous rappeler de les vérifier quand le minuteur de l'étape sonne.

```gram
[Pétrir] Jusqu'à ce que la pâte soit ={lisse} et ={élastique}(elle se rétracte doucement quand on l'étire).
```

Comme pour les minuteurs et les températures, les étapes courtes sont plus faciles à suivre. Si deux états concluent des actions distinctes, séparez-les en deux étapes plutôt que de les enchaîner :

```gram
[Faire fondre] Le @beurre{50 g} jusqu'à ={noisette}.

[Refroidir] Laisser refroidir jusqu'à ce qu'il soit ={tiède}, puis y incorporer les @œufs{2}.
```

## Erreurs

Un état attendu ne peut pas être vide et doit se refermer sur la même ligne. `={}` ou `={ruban` (sans `}`) provoquent une erreur de syntaxe pointant sur l'ouverture.

Un `=` qui ne précède pas `{` reste du texte ordinaire, et le modificateur de quantité fixe `@=sel{1 c.à.c}` reste inchangé.
