## Asynchronous tasks

### Asynchronous tasks support

You can now mark timers as asynchronous (background tasks) using the `&` modifier (e.g. `~{1h}&`).

* **Compiler**: Calculates distinct `totalTime` and `activeTime` metrics.
* **Playground**: Visualizes async tasks with dedicated styling (dashed borders and an hourglass icon) in both Markdown and preview modes.

> Synchronous timers represent active work that blocks the cook, while asynchronous timers (`&`) designate background tasks occurring in parallel. This distinction allows the compiler to calculate real effort versus total duration and lays the groundwork for timeline views.

### Playground improvements

* **New AST view**: Added a raw AST view mode to inspect parser output.
* **UI**: Improved view selection with a new dropdown menu.

### Bug fixes & documentation

* Fixed an issue where multiple composite ingredients would not aggregate correctly in the shopping list.
* Added tips across the documentation explaining the philosophy behind timers, cookware, and relative quantities.
