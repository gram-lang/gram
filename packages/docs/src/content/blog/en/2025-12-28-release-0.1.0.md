## Gram alpha — initial release

**Gram (General Recipe Abstract Markup)** is a strictly typed, data-first recipe markup language designed for developers. This initial alpha release introduces the language specification, the reference parser, and the essential tools to start treating recipes as code.

### The Gram language

Gram captures the **logic** of cooking, not just the text:

* **Data vs. narrative separation**: Clear distinction between ingredients, cookware, and instructions.
* **Mise en place**: Automatic generation of aggregated shopping lists alongside step-by-step section lists.
* **Relative quantities**: Native support for percentages (such as baker's math).
* **References & composites**: Reuse prepared intermediates and smartly aggregate composite ingredients (e.g. lemon zest + lemon juice → 1 lemon on the shopping list).

### The ecosystem

* **`gram-parser`**: The reference parser (built on Ohm.js) converting `.gram` files into a strict AST and structured JSON.
* **Playground**: A web-based IDE to write, visualize, and inspect recipes in real time (JSON, AST tree, and Markdown views).
* **VS Code extension**: Syntax highlighting support for `.gram` files.
