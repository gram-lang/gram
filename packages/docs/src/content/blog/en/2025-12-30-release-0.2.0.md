## TypeScript migration for `gram-parser`

This refactor migrates the entire `gram-parser` codebase from JavaScript to TypeScript to improve robustness and maintainability.

### Key changes

* **TypeScript**: Converted all source files to TypeScript (`src/*.ts`).
* **Strict typing**: Added comprehensive interface definitions for the AST and internal compiler structures.
* **Build**: Added a compilation step (`npm run build`) generating JavaScript output and `.d.ts` declaration files in `dist/`.

No changes were made to the `.gram` grammar itself.
