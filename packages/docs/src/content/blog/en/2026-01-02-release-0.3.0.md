## Architecture refactor

The project has been restructured into a monorepo to improve scalability, maintainability, and developer experience.

### Major restructuring

All code modules now live in a centralized `packages/` directory:

* `packages/parser`: Core parsing logic (formerly `gram-parser`).
* `packages/compiler`: Compiler and graph logic (formerly `gram-compiler`).
* `packages/playground`: The web-based IDE.
* `packages/vscode-extension`: Visual Studio Code language support.

The root `package.json` now manages workspaces with a single install command, paired with a shared `tsconfig.base.json`.

### Separation of parser & compiler

The compiler logic has been **extracted** from the parser:

* **Parser (`packages/parser`)**: Strictly responsible for the Ohm.js grammar and generating the raw AST.
* **Compiler (`packages/compiler`)**: Responsible for semantic analysis, graph generation, and transforming the AST into usable outputs (shopping lists, instructions, …).

This separation lets lightweight tools like linters or syntax highlighters depend on the parser without pulling in the full compiler.

### Developer experience

* Added unified root scripts (`npm run build`, `npm run dev`).
* Created a dedicated `examples/` folder at the repository root, automatically synced with the Playground dropdown menu.
* Updated `README.md` and `CONTRIBUTING.md` to reflect the new architecture.
