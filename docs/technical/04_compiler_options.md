# Compiler Options

The Gram compiler can be configured using the `CompilerOptions` object. This allows you to enable or disable experimental features and control the amount of metadata included in the output.

## Interface

```typescript
export interface CompilerOptions {
    /**
     * Enable/Disable Mass Normalization.
     * When true, the compiler attempts to convert all units to grams.
     * Default: false
     */
    enableMassNormalization?: boolean;

    /**
     * Enable/Disable Yield Management (Waste Factor).
     * Requires enableMassNormalization to be true.
     * Default: false
     */
    enableYieldManagement?: boolean;

    /**
     * Enable/Disable Nutritional Estimation.
     * Default: false
     */
    enableNutritionalEstimation?: boolean;
}
```

## Usage

When calling the `compile` function, pass the options object as the second argument:

```typescript
import { getAST } from 'gram-parser';
import { compile } from 'gram-compiler';

const ast = getAST(recipeSource);

const options = {
    enableMassNormalization: true,
    enableYieldManagement: true,
    enableNutritionalEstimation: true
};

const result = compile(ast, options);
```

## Feature Gating Logic

To ensure a clean output and prevent data leakage, the compiler follows strict gating rules:

1.  **Strict Pruning**: If a feature flag is set to `false` (or omitted), any metadata generated by that feature (e.g., `normalizedMass`, `purchasingMass`, `calories`) is **entirely removed** from the final JSON/AST output.
2.  **Warning Suppression**: Feature-specific warnings (e.g., `MISSING_MASS_DATA`) are automatically muted when the corresponding feature is disabled.
3.  **Independence**: Nutritional Estimation can be enabled independently of Mass Normalization. It will perform internal mass calculations for data lookup purposes without including mass metadata in the output.
4.  **Dependencies**: Yield Management depends on Mass Normalization. If `enableMassNormalization` is false, Yield Management will remain inactive even if `enableYieldManagement` is true.
